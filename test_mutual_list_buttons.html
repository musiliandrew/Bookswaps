🤝 Mutual List Button Logic - Should NOT Have "Follow Back"

🤔 The Question: Should Mutual List Have "Follow Back"?

Answer: NO! Here's why:

  • Mutual = Already following each other
  • "Follow Back" implies you're not following them yet
  • But in mutual list, you ARE following them (that's why it's mutual!)
👥 Followers
People who follow you
A
Alice
✅ "Follow Back" makes sense - Alice follows you, but you don't follow Alice yet
➡️ Following
People you follow
B
Bob
✅ "Following" makes sense - you follow Bob, click to unfollow
🤝 Mutual
People who follow each other
C
Charlie Mutual
✅ "Following" is correct - you follow Charlie (and Charlie follows you)
❌ WRONG: Mutual with "Follow Back"
This would be confusing: "Follow Back" in mutual list implies you're not following them, but you are!
C
Charlie Mutual

🚫 This doesn't make sense - if it's mutual, you're already following each other!

✅ CORRECT: Mutual with "Following"
This makes sense: "Following" shows your current state, click to unfollow (breaks mutual)

Charlie Mutual

✅ Clear actions: "Following" = unfollow, "Remove" = remove as follower

🎯 Button Logic Summary

List Type Relationship Button Text Logic
Followers They follow you Follow Back / Following Depends if you follow them back
Following You follow them Following You follow them by definition
Mutual ✅ Both follow each other Following You follow them by definition

🔧 Code Logic

// Determine if user is actually following
const isFollowerList = listType === 'followers';
const isMutualList = listType === 'mutual';
const isFollowingList = listType === 'following';

// For following list OR mutual list, we know user is following these people
const isActuallyFollowing = followStatus.is_following || isFollowingList || isMutualList;

// Button text logic
if (isActuallyFollowing) {
  return 'Following'; // Correct for both following and mutual lists
} else {
  return isFollowerList ? 'Follow Back' : 'Follow'; // Only followers list gets "Follow Back"
}
